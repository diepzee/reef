# rif v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A deployed headless Python app owning a Postgres store and exposing a remote MCP server, giving two people an assistant with long-term memory across a private space each plus a shared household space.

**Architecture:** One store, one write path, one enforcement point. Every content operation passes through a single accessor that resolves a space alias against `memberships` for an authenticated principal — nothing else in the app queries content tables. The primary retrieval tool returns the entire corpus the principal can see in one call rather than searching it. Transport is stdio in development and streamable HTTP with OAuth in production, so auth is isolated to a late phase and never blocks a working server.

**Tech Stack:** Python 3.13, uv, ruff, FastMCP, SQLAlchemy 2.0 (async) + Alembic, asyncpg, pytest + pytest-asyncio against a real Postgres, S3-compatible object storage, Fly.io.

## Global Constraints

- Python 3.13. Modern types (`X | None`, builtin generics). ReST docstrings without types — type hints carry types. Docstrings are mandatory on every public function and class.
- Every content read/write goes through `rif.access` — no module outside it may query `pages`, `revisions`, or `attachments`.
- Page functions take `(session, principal, alias, ...)` and never accept a `Space` object from a caller. The accessor must be unbypassable within the app, not merely conventional.
- Space aliases in all tool signatures are `"personal"` and `"household"`. Space ids, slugs, and other people's space names never cross the tool boundary.
- `remember` defaults to `space="personal"`. Private-by-default lives in the signature, not in prose.
- Integration tests run against a real Postgres. Mocked repositories are not acceptable for anything touching the access model.
- No secrets in the repo. All configuration from the environment.
- Commit after every task.

from datetime import datetime
from enum import StrEnum
from uuid import UUID, uuid4

from sqlalchemy import ARRAY, ForeignKey, String, UniqueConstraint, func
from sqlalchemy.orm import DeclarativeBase, Mapped, mapped_column


class SpaceKind(StrEnum):
    """The two kinds of space a person can belong to."""

    PERSONAL = "personal"
    HOUSEHOLD = "household"


class Base(DeclarativeBase):
    """Declarative base for all rif tables."""


class Person(Base):
    """A human principal. Email is identity."""

    __tablename__ = "persons"

    id: Mapped[UUID] = mapped_column(primary_key=True, default=uuid4)
    email: Mapped[str] = mapped_column(unique=True)
    display_name: Mapped[str]


class Space(Base):
    """A knowledge layer. Personal spaces have one member, household spaces two."""

    __tablename__ = "spaces"

    id: Mapped[UUID] = mapped_column(primary_key=True, default=uuid4)
    slug: Mapped[str] = mapped_column(unique=True)
    kind: Mapped[SpaceKind]


class Membership(Base):
    """The entire access model: who may see which space."""

    __tablename__ = "memberships"

    person_id: Mapped[UUID] = mapped_column(ForeignKey("persons.id"), primary_key=True)
    space_id: Mapped[UUID] = mapped_column(ForeignKey("spaces.id"), primary_key=True)


class Page(Base):
    """A markdown page within a space."""

    __tablename__ = "pages"
    __table_args__ = (UniqueConstraint("space_id", "path"),)

    id: Mapped[UUID] = mapped_column(primary_key=True, default=uuid4)
    space_id: Mapped[UUID] = mapped_column(ForeignKey("spaces.id"), index=True)
    path: Mapped[str]
    title: Mapped[str]
    tags: Mapped[list[str]] = mapped_column(ARRAY(String), default=list)
    body: Mapped[str]
    created_at: Mapped[datetime] = mapped_column(server_default=func.now())
    updated_at: Mapped[datetime] = mapped_column(
        server_default=func.now(), onupdate=func.now()
    )


class Revision(Base):
    """Append-only history. One row per write, holding the body as written."""

    __tablename__ = "revisions"

    id: Mapped[UUID] = mapped_column(primary_key=True, default=uuid4)
    page_id: Mapped[UUID] = mapped_column(ForeignKey("pages.id"), index=True)
    body: Mapped[str]
    message: Mapped[str]
    author_id: Mapped[UUID] = mapped_column(ForeignKey("persons.id"))
    created_at: Mapped[datetime] = mapped_column(server_default=func.now())


class Attachment(Base):
    """An image stored in object storage, described in text for context loading."""

    __tablename__ = "attachments"

    id: Mapped[UUID] = mapped_column(primary_key=True, default=uuid4)
    space_id: Mapped[UUID] = mapped_column(ForeignKey("spaces.id"), index=True)
    page_path: Mapped[str | None]
    object_key: Mapped[str] = mapped_column(unique=True)
    mime: Mapped[str]
    byte_size: Mapped[int]
    description: Mapped[str]
    created_at: Mapped[datetime] = mapped_column(server_default=func.now())

from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine

from rif.config import get_settings

@asynccontextmanager
async def session_scope() -> AsyncIterator[AsyncSession]:
    """Yield a session, committing on success and rolling back on error.

    :returns: an async context manager over a database session
    """
    async with _session_factory() as session:
        try:
            yield session
            await session.commit()
        except Exception:
            await session.rollback()
            raise

`src/rif/access.py`:

```python
from dataclasses import dataclass
from uuid import UUID

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from rif.models import Membership, Space, SpaceKind

_ALIASES = {
    "personal": SpaceKind.PERSONAL,
    "household": SpaceKind.HOUSEHOLD,
}


class AccessDenied(Exception):
    """Raised whenever a principal may not reach the requested space."""


@dataclass(frozen=True)
class Principal:
    """An authenticated person, as established by the transport layer."""

    person_id: UUID
    email: str


async def resolve_space(session: AsyncSession, principal: Principal, alias: str) -> Space:
    """Resolve a space alias to a space the principal is a member of.

    This is the only place membership is checked. Callers pass aliases, never
    space identifiers, so a principal has no vocabulary for another person's
    space.

    :param session: database session
    :param principal: the authenticated person
    :param alias: either ``personal`` or ``household``
    :raises AccessDenied: if the alias is unknown or resolves to no unique space
    :returns: the resolved space
    """
    kind = _ALIASES.get(alias)
    if kind is None:
        raise AccessDenied(f"unknown space alias: {alias!r}")

    stmt = (
        select(Space)
        .join(Membership, Membership.space_id == Space.id)
        .where(Membership.person_id == principal.person_id, Space.kind == kind)
    )
    spaces = (await session.scalars(stmt)).all()
    if len(spaces) != 1:
        raise AccessDenied(f"no unique {alias} space for {principal.email}")
    return spaces[0]


async def accessible_spaces(session: AsyncSession, principal: Principal) -> list[Space]:
    """Return every space the principal is a member of.

    :param session: database session
    :param principal: the authenticated person
    :returns: spaces, personal first
    """
    stmt = (
        select(Space)
        .join(Membership, Membership.space_id == Space.id)
        .where(Membership.person_id == principal.person_id)
        .order_by(Space.kind)
    )
    return list((await session.scalars(stmt)).all())
```

`src/rif/pages.py`:

```python
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal, resolve_space
from rif.models import Page, Revision


class SectionNotFound(Exception):
    """Raised when a surgical edit cannot find the text it was asked to replace."""


async def list_pages(session: AsyncSession, principal: Principal, alias: str) -> list[Page]:
    """List every page in one of the principal's spaces.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :returns: pages ordered by path
    """
    space = await resolve_space(session, principal, alias)
    stmt = select(Page).where(Page.space_id == space.id).order_by(Page.path)
    return list((await session.scalars(stmt)).all())


async def get_page(
    session: AsyncSession, principal: Principal, alias: str, path: str
) -> Page | None:
    """Fetch a single page by path.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :param path: page path, for example ``house.md``
    :returns: the page, or None if it does not exist in that space
    """
    space = await resolve_space(session, principal, alias)
    stmt = select(Page).where(Page.space_id == space.id, Page.path == path)
    return await session.scalar(stmt)


async def save_page(
    session: AsyncSession,
    principal: Principal,
    alias: str,
    path: str,
    body: str,
    *,
    message: str,
    title: str | None = None,
    tags: list[str] | None = None,
) -> Page:
    """Create or overwrite a page and record a revision.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :param path: page path
    :param body: full markdown body
    :param message: why this write happened, stored on the revision
    :param title: human-readable title; defaults to the path stem on creation
    :param tags: page tags; left unchanged on update when omitted
    :returns: the saved page
    """
    space = await resolve_space(session, principal, alias)
    page = await session.scalar(
        select(Page).where(Page.space_id == space.id, Page.path == path)
    )
    if page is None:
        page = Page(
            space_id=space.id,
            path=path,
            title=title or path.removesuffix(".md"),
            tags=tags or [],
            body=body,
        )
        session.add(page)
        await session.flush()
    else:
        page.body = body
        if title is not None:
            page.title = title
        if tags is not None:
            page.tags = tags

    session.add(
        Revision(
            page_id=page.id,
            body=body,
            message=message,
            author_id=principal.person_id,
        )
    )
    await session.flush()
    return page


async def edit_section(
    session: AsyncSession,
    principal: Principal,
    alias: str,
    path: str,
    old_text: str,
    new_text: str,
    *,
    message: str,
) -> Page:
    """Replace an exact span of a page, leaving the rest untouched.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :param path: page path
    :param old_text: exact text to replace; must appear exactly once
    :param new_text: replacement text
    :param message: why this write happened
    :raises SectionNotFound: if the page is missing, or the text is absent or ambiguous
    :returns: the saved page
    """
    page = await get_page(session, principal, alias, path)
    if page is None:
        raise SectionNotFound(f"no page at {path!r}")
    occurrences = page.body.count(old_text)
    if occurrences != 1:
        raise SectionNotFound(
            f"expected exactly one occurrence of the text in {path!r}, found {occurrences}"
        )
    return await save_page(
        session,
        principal,
        alias,
        path,
        page.body.replace(old_text, new_text),
        message=message,
    )
```

```python
from dataclasses import dataclass

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal, accessible_spaces
from rif.models import Attachment, Page, Space, SpaceKind

_ALIAS_BY_KIND = {
    SpaceKind.PERSONAL: "personal",
    SpaceKind.HOUSEHOLD: "household",
}


@dataclass
class SpaceContext:
    """Everything the principal may see in one space."""

    alias: str
    pages: list[dict]
    attachments: list[dict]


@dataclass
class ContextPayload:
    """The whole corpus a principal may see, plus loading metadata."""

    version: str
    truncated: bool
    note: str | None
    spaces: list[SpaceContext]


def _page_entry(page: Page, body: str | None) -> dict:
    return {
        "path": page.path,
        "title": page.title,
        "tags": list(page.tags),
        "updated": page.updated_at.isoformat(),
        "body": body,
    }


async def load_context(
    session: AsyncSession, principal: Principal, *, char_budget: int
) -> ContextPayload:
    """Return every page in every space the principal can see.

    Pages are included in full until the character budget is exhausted, most
    recently updated first. Anything beyond the budget still appears in the
    payload with a null body, so the model can see that it exists and fetch it
    with ``read_page``. The payload is never silently short.

    :param session: database session
    :param principal: the authenticated person
    :param char_budget: approximate ceiling on total body characters
    :returns: the assembled context payload
    """
    spaces = await accessible_spaces(session, principal)
    space_ids = [space.id for space in spaces]

    pages = list(
        (
            await session.scalars(
                select(Page)
                .where(Page.space_id.in_(space_ids))
                .order_by(Page.updated_at.desc())
            )
        ).all()
    )
    attachments = list(
        (
            await session.scalars(
                select(Attachment).where(Attachment.space_id.in_(space_ids))
            )
        ).all()
    )

    spent = 0
    included: dict[Page, str | None] = {}
    for page in pages:
        if spent + len(page.body) <= char_budget:
            included[page] = page.body
            spent += len(page.body)
        else:
            included[page] = None

    truncated = any(body is None for body in included.values())
    omitted = sum(1 for body in included.values() if body is None)
    note = (
        f"{omitted} page(s) exceeded the context budget and are listed without "
        "bodies. Fetch them with read_page when relevant."
        if truncated
        else None
    )

    by_space: dict[Space, SpaceContext] = {
        space: SpaceContext(alias=_ALIAS_BY_KIND[space.kind], pages=[], attachments=[])
        for space in spaces
    }
    space_by_id = {space.id: space for space in spaces}
    for page in sorted(pages, key=lambda p: p.path):
        by_space[space_by_id[page.space_id]].pages.append(
            _page_entry(page, included[page])
        )
    for attachment in attachments:
        by_space[space_by_id[attachment.space_id]].attachments.append(
            {
                "key": attachment.object_key,
                "page": attachment.page_path,
                "mime": attachment.mime,
                "description": attachment.description,
            }
        )

    version = (
        max((page.updated_at for page in pages), default=None).isoformat()
        if pages
        else "empty"
    )
    return ContextPayload(
        version=version,
        truncated=truncated,
        note=note,
        spaces=list(by_space.values()),
    )
```

import os

from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import AccessDenied, Principal
from rif.models import Person


async def current_principal(session: AsyncSession) -> Principal:
    """Resolve the authenticated principal for the current request.

    Over stdio there is no transport identity, so the principal comes from
    ``RIF_DEV_PRINCIPAL_EMAIL``. Task 12 replaces this with validated OAuth
    claims; nothing else in the app changes when it does.

    :param session: database session
    :raises AccessDenied: if no matching person exists
    :returns: the authenticated principal
    """
    email = os.environ.get("RIF_DEV_PRINCIPAL_EMAIL")
    if not email:
        raise AccessDenied("no principal on this connection")
    person = await session.scalar(select(Person).where(Person.email == email))
    if person is None:
        raise AccessDenied(f"unknown principal: {email}")
    return Principal(person_id=person.id, email=person.email)

from dataclasses import asdict

from fastmcp import FastMCP
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal, accessible_spaces
from rif.auth import current_principal
from rif.config import get_settings
from rif.context import load_context
from rif.db import session_scope
from rif.pages import get_page

mcp = FastMCP("rif")


async def tool_load_context(session: AsyncSession, principal: Principal) -> dict:
    """Assemble the whole-corpus payload for a principal.

    Split from the MCP tool wrapper so it can be tested without a transport.

    :param session: database session
    :param principal: the authenticated person
    :returns: the context payload as a plain dict
    """
    payload = await load_context(
        session, principal, char_budget=get_settings().context_char_budget
    )
    return asdict(payload)


async def tool_read_page(
    session: AsyncSession, principal: Principal, space: str, path: str
) -> dict:
    """Fetch one page.

    :param session: database session
    :param principal: the authenticated person
    :param space: ``personal`` or ``household``
    :param path: page path
    :returns: the page as a dict, or ``{"error": "not_found"}``
    """
    page = await get_page(session, principal, space, path)
    if page is None:
        return {"error": "not_found", "path": path}
    return {
        "path": page.path,
        "title": page.title,
        "tags": list(page.tags),
        "body": page.body,
        "updated": page.updated_at.isoformat(),
    }


@mcp.tool
async def load_all_context() -> dict:
    """Load everything you can see. Call this first, every conversation.

    Returns all pages in the user's personal space and the shared household
    space. If ``truncated`` is true, some bodies are omitted and listed with a
    null body — fetch those with ``read_page``.
    """
    async with session_scope() as session:
        principal = await current_principal(session)
        return await tool_load_context(session, principal)


@mcp.tool
async def read_page(space: str, path: str) -> dict:
    """Read one page by path. Only needed when load_all_context was truncated.

    :param space: ``personal`` or ``household``
    :param path: page path, for example ``house.md``
    """
    async with session_scope() as session:
        principal = await current_principal(session)
        return await tool_read_page(session, principal, space, path)


@mcp.tool
async def list_spaces() -> list[dict]:
    """List the spaces you can see."""
    async with session_scope() as session:
        principal = await current_principal(session)
        spaces = await accessible_spaces(session, principal)
        return [{"alias": space.kind.value, "slug": space.slug} for space in spaces]


def main() -> None:
    """Run the server over stdio for local development."""
    mcp.run()


if __name__ == "__main__":
    main()

from datetime import UTC, datetime

from rif.pages import edit_section, save_page

_INBOX = "inbox.md"


async def tool_remember(
    session: AsyncSession, principal: Principal, fact: str, space: str = "personal"
) -> dict:
    """Append one fact to a space's inbox page, creating it if needed.

    The default is deliberately the personal space: promoting a fact to the
    household space is reversible in intent but not in effect, so the default
    must be the private one.

    :param session: database session
    :param principal: the authenticated person
    :param fact: the text to record
    :param space: ``personal`` or ``household``
    :returns: a summary of what was written
    """
    existing = await get_page(session, principal, space, _INBOX)
    stamp = datetime.now(UTC).date().isoformat()
    entry = f"- ({stamp}) {fact}"
    body = f"{existing.body}\n{entry}" if existing else f"# Inbox\n\n{entry}"
    await save_page(
        session, principal, space, _INBOX, body,
        message=f"remember: {fact[:60]}", title="Inbox",
    )
    return {"space": space, "path": _INBOX, "appended": entry}


@mcp.tool
async def remember(fact: str, space: str = "personal") -> dict:
    """Record a fact. Defaults to the private personal space.

    Only pass space="household" when the fact concerns a jointly-owned thing, a
    joint decision, or a shared obligation. Anything ambiguous is personal.

    :param fact: the text to record
    :param space: ``personal`` or ``household``
    """
    async with session_scope() as session:
        principal = await current_principal(session)
        return await tool_remember(session, principal, fact, space)


@mcp.tool
async def write_page(
    space: str,
    path: str,
    body: str,
    message: str,
    title: str | None = None,
    tags: list[str] | None = None,
) -> dict:
    """Create or replace a whole page. Prefer edit_page_section for small changes.

    :param space: ``personal`` or ``household``
    :param path: page path, for example ``house.md``
    :param body: the full markdown body
    :param message: why this change is being made
    :param title: human-readable title
    :param tags: page tags
    """
    async with session_scope() as session:
        principal = await current_principal(session)
        page = await save_page(
            session, principal, space, path, body,
            message=message, title=title, tags=tags,
        )
        return {"space": space, "path": page.path, "updated": page.updated_at.isoformat()}


@mcp.tool
async def edit_page_section(
    space: str, path: str, old_text: str, new_text: str, message: str
) -> dict:
    """Replace an exact span of a page, leaving everything else untouched.

    The old text must appear exactly once. This is the preferred way to change
    a page: it keeps edits surgical and reviewable.

    :param space: ``personal`` or ``household``
    :param path: page path
    :param old_text: exact text to replace
    :param new_text: replacement text
    :param message: why this change is being made
    """
    async with session_scope() as session:
        principal = await current_principal(session)
        page = await edit_section(
            session, principal, space, path, old_text, new_text, message=message
        )
        return {"space": space, "path": page.path, "updated": page.updated_at.isoformat()}

from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal
from rif.pages import get_page, save_page


class PromotionNotConfirmed(Exception):
    """Raised when a promotion is attempted without explicit confirmation."""


async def promote(
    session: AsyncSession, principal: Principal, path: str, *, confirm: bool
) -> dict:
    """Copy a personal page into the household space and stub the original.

    There is no inverse operation. Once a page is in the household space the
    other member has read it or may have, so the confirmation flag is the only
    gate that exists.

    :param session: database session
    :param principal: the authenticated person
    :param path: page path in the personal space
    :param confirm: must be True; the caller has to say so deliberately
    :raises PromotionNotConfirmed: if unconfirmed, or the page does not exist
    :returns: a summary of the promotion
    """
    if not confirm:
        raise PromotionNotConfirmed(
            f"{path} was not promoted: confirm=True is required, and promotion "
            "cannot be undone"
        )
    page = await get_page(session, principal, "personal", path)
    if page is None:
        raise PromotionNotConfirmed(f"no personal page at {path!r}")

    await save_page(
        session, principal, "household", path, page.body,
        message=f"promoted from personal by {principal.email}",
        title=page.title, tags=list(page.tags),
    )
    await save_page(
        session, principal, "personal", path,
        f"# {page.title}\n\nMoved to the household space; see `{path}` there.",
        message="stubbed after promotion",
        title=page.title, tags=list(page.tags),
    )
    return {"path": path, "promoted": True}
```

from hashlib import sha256
from typing import Protocol
from uuid import uuid4

import boto3
from sqlalchemy import select
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal, resolve_space
from rif.config import get_settings
from rif.models import Attachment


class ObjectStore(Protocol):
    """Blob storage for attachment bytes."""

    def put(self, key: str, data: bytes, mime: str) -> None:
        """Store bytes under a key."""

    def signed_url(self, key: str, expires_in: int) -> str:
        """Return a time-limited URL for a key."""


class S3ObjectStore:
    """S3-compatible object store (Tigris on Fly, R2 on Cloudflare)."""

    def __init__(self) -> None:
        settings = get_settings()
        self._bucket = settings.s3_bucket
        self._client = boto3.client(
            "s3",
            endpoint_url=settings.s3_endpoint,
            aws_access_key_id=settings.s3_access_key,
            aws_secret_access_key=settings.s3_secret_key,
        )

    def put(self, key: str, data: bytes, mime: str) -> None:
        """Store bytes under a key.

        :param key: object key
        :param data: raw bytes
        :param mime: content type
        """
        self._client.put_object(Bucket=self._bucket, Key=key, Body=data, ContentType=mime)

    def signed_url(self, key: str, expires_in: int) -> str:
        """Return a time-limited URL for a key.

        :param key: object key
        :param expires_in: lifetime in seconds
        :returns: presigned URL
        """
        return self._client.generate_presigned_url(
            "get_object",
            Params={"Bucket": self._bucket, "Key": key},
            ExpiresIn=expires_in,
        )


async def add_attachment(
    session: AsyncSession,
    principal: Principal,
    alias: str,
    data: bytes,
    mime: str,
    *,
    description: str,
    store: ObjectStore,
    page_path: str | None = None,
) -> Attachment:
    """Store an image and record its metadata and text description.

    The description is what makes images usable in a load-everything design:
    bytes cannot go into context every turn, but their descriptions can.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :param data: image bytes
    :param mime: content type
    :param description: text description, always required
    :param store: object store to write to
    :param page_path: page this image belongs to, if any
    :returns: the stored attachment
    """
    space = await resolve_space(session, principal, alias)
    digest = sha256(data).hexdigest()[:16]
    key = f"{space.id}/{uuid4().hex}-{digest}"
    store.put(key, data, mime)
    attachment = Attachment(
        space_id=space.id,
        page_path=page_path,
        object_key=key,
        mime=mime,
        byte_size=len(data),
        description=description,
    )
    session.add(attachment)
    await session.flush()
    return attachment


async def get_attachment(
    session: AsyncSession, principal: Principal, alias: str, key: str
) -> Attachment | None:
    """Fetch attachment metadata, scoped to a space the principal can see.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :param key: object key
    :returns: the attachment, or None if it is not in that space
    """
    space = await resolve_space(session, principal, alias)
    stmt = select(Attachment).where(
        Attachment.space_id == space.id, Attachment.object_key == key
    )
    return await session.scalar(stmt)
```

```python
from pathlib import Path

import yaml
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal
from rif.pages import save_page


def parse_markdown(text: str) -> tuple[dict, str]:
    """Split YAML frontmatter from a markdown body.

    :param text: the file contents
    :returns: a tuple of the frontmatter mapping and the remaining body
    """
    if not text.startswith("---\n"):
        return {}, text
    _, _, remainder = text.partition("---\n")
    raw_meta, separator, body = remainder.partition("\n---\n")
    if not separator:
        return {}, text
    return yaml.safe_load(raw_meta) or {}, body


async def import_directory(
    session: AsyncSession,
    principal: Principal,
    source: Path,
    alias: str,
    only: set[str] | None = None,
) -> int:
    """Import markdown files from a directory into one space.

    Nothing is imported by inference: pass the exact filenames. Which page
    belongs in which space is a decision recorded in the architecture document,
    not something this function guesses.

    :param session: database session
    :param principal: the authenticated person
    :param source: directory holding markdown files
    :param alias: ``personal`` or ``household``
    :param only: filenames to import; None imports every ``.md`` file
    :returns: number of pages imported
    """
    imported = 0
    for path in sorted(source.glob("*.md")):
        if only is not None and path.name not in only:
            continue
        meta, body = parse_markdown(path.read_text())
        await save_page(
            session, principal, alias, path.name, body.strip(),
            message=f"imported from {source.name}/{path.name}",
            title=meta.get("title", path.stem),
            tags=list(meta.get("tags", [])),
        )
        imported += 1
    return imported
```

async def principal_from_claims(session: AsyncSession, claims: dict) -> Principal:
    """Resolve a principal from verified token claims.

    The allowlist is the ``persons`` table: a verified email with no matching
    row is denied. This is an allowlist, not an identity system, and should not
    grow into one.

    :param session: database session

    :raises AccessDenied: if the email claim is missing or unknown

    email = claims.get("email")

    person = await session.scalar(select(Person).where(Person.email == email))
    if person is None:
        raise AccessDenied(f"unknown principal: {email}")
    return Principal(person_id=person.id, email=person.email)

from pathlib import Path

import yaml
from sqlalchemy.ext.asyncio import AsyncSession

from rif.access import Principal
from rif.models import Page
from rif.pages import list_pages


def render_page(page: Page) -> str:
    """Render a page as markdown with YAML frontmatter.

    The output is what the importer reads, so a mirror can restore a lost
    database.

    :param page: the page to render
    :returns: markdown text
    """
    meta = {
        "title": page.title,
        "tags": list(page.tags),
        "updated": page.updated_at.date().isoformat(),
    }
    front = yaml.safe_dump(meta, sort_keys=False, allow_unicode=True).strip()
    return f"---\n{front}\n---\n\n{page.body}\n"


async def export_space(
    session: AsyncSession, principal: Principal, alias: str, target: Path
) -> int:
    """Write every page in a space to a directory as markdown.

    One-way: this overwrites whatever is in the target. Nothing reads back from
    the mirror.

    :param session: database session
    :param principal: the authenticated person
    :param alias: ``personal`` or ``household``
    :param target: directory to write into
    :returns: number of files written
    """
    target.mkdir(parents=True, exist_ok=True)
    pages = await list_pages(session, principal, alias)
    for page in pages:
        destination = target / page.path
        destination.parent.mkdir(parents=True, exist_ok=True)
        destination.write_text(render_page(page))
    return len(pages)
```

    subprocess.run(["git", "-C", str(repo), "add", "-A"], check=True)
    status = subprocess.run(
        ["git", "-C", str(repo), "status", "--porcelain"],
        check=True, capture_output=True, text=True,
    )
    if not status.stdout.strip():
        return
    body = "\n".join(f"- {line}" for line in details)
    message = f"{summary}\n\n{body}" if body else summary
    subprocess.run(["git", "-C", str(repo), "commit", "-m", message], check=True)
    subprocess.run(["git", "-C", str(repo), "push"], check=True)
```

The export job selects `Revision` rows created since the previous run and
passes their `message` values as `details`.

### Task 14: Backups and a restore drill

**Files:**
- Create: `scripts/backup.sh`, `docs/restore.md`

GitHub never needed backing up; Postgres does. The mirror from Task 13 covers
page content only — it does not carry revisions, attachment metadata, or
memberships. Those need a real dump.

An untested backup is not a backup, so this task ends with a restore, not with a
dump appearing in a bucket.

- [ ] **Step 1: Enable Railway's managed backups and R2 versioning**

In the Railway dashboard, enable scheduled backups on the Postgres service and
confirm the retention window. In the Cloudflare dashboard, enable object
versioning on the R2 bucket — `pg_dump` covers attachment metadata but not the
bytes, and versioning is the one-checkbox answer to accidental deletion. Note
both in `docs/restore.md`.

- [ ] **Step 2: Write an independent dump script**

Managed backups live with the provider; keep one copy that does not. `scripts/backup.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail

: "${DATABASE_URL:?DATABASE_URL must be set}"
: "${BACKUP_DIR:?BACKUP_DIR must be set}"

stamp="$(date -u +%Y%m%dT%H%M%SZ)"
mkdir -p "$BACKUP_DIR"
pg_dump --format=custom "$DATABASE_URL" > "$BACKUP_DIR/rif-$stamp.dump"
find "$BACKUP_DIR" -name 'rif-*.dump' -mtime +30 -delete
echo "wrote $BACKUP_DIR/rif-$stamp.dump"
```

```bash
chmod +x scripts/backup.sh
```

- [ ] **Step 3: Take a dump against the deployed database**

```bash
DATABASE_URL="$(railway variables --json | jq -r .DATABASE_URL)" \
  BACKUP_DIR=~/backups/rif ./scripts/backup.sh
```

Expected: a `.dump` file with non-zero size.

- [ ] **Step 4: Restore it into a scratch database and verify**

```bash
docker compose exec db createdb -U rif rif_restore
pg_restore --clean --if-exists \
  --dbname "postgresql://rif:rif@localhost:5433/rif_restore" \
  ~/backups/rif/rif-*.dump
docker compose exec db psql -U rif -d rif_restore \
  -c "select (select count(*) from pages) as pages,
             (select count(*) from revisions) as revisions,
             (select count(*) from memberships) as memberships;"
```

Expected: counts matching production. If memberships is zero, the restore is
useless — the access model is the part that must survive.

- [ ] **Step 5: Write down the restore procedure**

`docs/restore.md` records: where managed backups live and their retention, where
independent dumps go, the exact `pg_restore` invocation from Step 4, and the
fact that the git mirror is a content-only fallback of last resort that loses
revisions, attachments, and memberships.
