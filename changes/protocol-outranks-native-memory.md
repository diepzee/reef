Your assistant now treats reef as the record when its own built-in memory
disagrees — it tells you both sides instead of quietly picking one, and
writes down whichever answer you settle on. Assistants limited to search
and fetch, like ChatGPT connectors outside developer mode, are now offered
the operating protocol as the first search result, so they arrive knowing
how to read and write your memory too.
