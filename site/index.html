Yours, actually

Built to be trusted with a life

A shared memory only works when ownership is clear, consent is visible, and leaving is always possible.

Private by architecture

Your personal cove is invisible to everyone else — enforced row by row in the database itself, not by app code promising to behave.

Sharing is consent

Nothing moves from private to shared without an explicit yes, and a shared cove always shows exactly who can read it.

Leave with everything

One export turns every page into plain files on your machine. Your memory outlives any service — including this one.

Setup

Add reef to Claude

Two minutes, once. After this every conversation — desktop, web, or the phone app — starts already knowing.

Open Claude's connectors

In Claude, go to Settings → Connectors, then choose to add a custom connector.

Paste this address

That is this site, with /mcp on the end.

/mcp

Sign in once

Claude opens a sign-in page. Use the email you want reef to know you by — it is how invitations to a cove reach you.

Connect reef in the ChatGPT desktop app. The same MCP setup is then available to Codex on this computer.

Open MCP servers

In the ChatGPT desktop app, go to Settings → MCP servers, then select Add server.

Add reef

Name it reef, choose Streamable HTTP, paste this address, and save. Then select Restart.

/mcp

Sign in once

Back in MCP servers, select Authenticate. Use the email you want reef to know you by — it is how invitations to a cove reach you.

Two commands, once. Codex and the ChatGPT desktop app share this MCP setup on the same computer.

Open a terminal

Make sure the Codex CLI is installed and signed in, then add reef as a remote MCP server.

Add reef

Run this command once:

codex mcp add reef --url /mcp

Sign in once

Run this command, then finish signing in in your browser:

codex mcp login reef

The reef CLI mirrors every MCP tool as JSON, and the bundled skill teaches agents how to retrieve, write, and share memory safely.

Install the CLI

With uv installed, run:

uv tool install reef-cli

Prefer Node? A minimal twin ships on npm — login, tools, and the raw call passthrough:

npm install -g @haai/reef-cli

Sign in once

The CLI opens the same secure browser sign-in as the MCP connection:

reef login

Give your agent the skill

Ask an agent with skill support to install the bundled Reef workflow:

Install the Reef skill from https://github.com/diepzee/reef/tree/main/skills/reef
