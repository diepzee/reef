Coves

A cove for every circle of your life

A cove is a small group and its shared memory: the people you invite, the pages you keep, its own colour and creature. Start one for anything that has a "we" — and everyone always keeps a private cove that's theirs alone.

How it works

Tell it once

Start a cove, invite your people

Your household, the school circle, you and the accountant. Invites go by email; whoever starts a cove looks after it.

Grow pages together

Memory lives in real pages you can open and edit — not a black box. Your assistant writes them mid-conversation; you garden them whenever you care to.

Every conversation starts knowing

Connect through MCP, or give any capable agent the reef CLI and matching skill. The school schedule, the house quirks, the plan so far — known at hello.

Under the surface

A wiki, not a memory blob

reef gives your assistant a small, inspectable map of human-readable pages, then lets it fetch and tend the right ones.

pages/*.md

Readable by default

Every page is Markdown: plain text with headings, lists, links, and images. Open it, edit it, or export everything whenever you like.

index

Map before memory

Your assistant first gets titles, tags, and one-line descriptions — not every page body. reef rebuilds that index from the live pages, so it cannot drift.

read → write

Only what matters

It opens relevant pages as the conversation unfolds, then can file useful new facts back. Each chat leaves the wiki a little better for the next one.

Inspired by Andrej Karpathy's LLM Wiki: a persistent, compounding wiki maintained by an LLM. reef adapts the idea for shared, permissioned memory and makes it available through MCP.

Setup

Add reef to Claude

Two minutes, once. After this every conversation — desktop, web, or the phone app — starts already knowing.

Open Claude's connectors

In Claude, go to Settings → Connectors, then choose to add a custom connector.

Paste this address

That is this site, with /mcp on the end.

/mcp

Sign in once

Claude opens a sign-in page. Use the email you want reef to know you by — it is how invitations to a cove reach you.

Connect reef in the ChatGPT desktop app. The same MCP setup is then available to Codex on this computer.

Open MCP servers

In the ChatGPT desktop app, go to Settings → MCP servers, then select Add server.

Add reef

Name it reef, choose Streamable HTTP, paste this address, and save. Then select Restart.

/mcp

Sign in once

Back in MCP servers, select Authenticate. Use the email you want reef to know you by — it is how invitations to a cove reach you.

Two commands, once. Codex and the ChatGPT desktop app share this MCP setup on the same computer.

Open a terminal

Make sure the Codex CLI is installed and signed in, then add reef as a remote MCP server.

Add reef

Run this command once:

codex mcp add reef --url /mcp

Sign in once

Run this command, then finish signing in in your browser:

codex mcp login reef

The reef CLI mirrors every MCP tool as JSON, and the bundled skill teaches agents how to retrieve, write, and share memory safely.

Install the CLI

With uv installed, run:

uv tool install git+https://github.com/diepzee/rif.git

Sign in once

The CLI opens the same secure browser sign-in as the MCP connection:

reef login

Give your agent the skill

Ask an agent with skill support to install the bundled Reef workflow:

Install the Reef skill from https://github.com/diepzee/rif/tree/main/skills/reef

Yours, actually

Built to be trusted with a life

Private by architecture

Your personal cove is invisible to everyone else — enforced row by row in the database itself, not by app code promising to behave.

Sharing is consent

Nothing moves from private to shared without an explicit yes, and a shared cove always shows exactly who can read it.

Leave with everything

One export turns every page into plain files on your machine. Your memory outlives any service — including this one.
