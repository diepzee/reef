---
name: remember
description: Save something to your Reef memory
argument-hint: <what to remember>
---

Record this in Reef: $ARGUMENTS

Use the `remember` tool. With no space named it writes to `personal`, which
only this person can ever read. If the fact plainly belongs to a shared space
(it concerns the household rather than them alone), say which space you intend
to write to, and why, *before* you write it.

If the request is an entry for a journal, a training log or meeting notes, use
`log` instead.

Then tell them the exact line you stored. Nothing reaches Reef that they have
not first seen you say you would store.
